# PR 4 — Day-1 Boot (Sub-Project B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ems-device-api fetches a JSON-serialized canonical Dtm from S3-compatible storage at startup, validates it against the bundled template catalog, and seeds the topology table — closing the gap between cold-boot and a working `/topology` + `/asyncapi` surface.

**Architecture:** One mechanism per ADR-003: S3 GET against a configurable URL with an optional endpoint override (real AWS S3 in cloud, minio on-prem, LocalStack in dev). New `seedFromS3` free function runs in `main.ts` bootstrap between `NestFactory.create` and `app.listen`. Fatal-on-error when URL is configured; graceful empty start when URL is unset (tests/CI). Idempotent on restart — populated topology is never overwritten.

**Tech Stack:** TypeScript 5.x, NestJS 11, Zod 4, `@aws-sdk/client-s3` v3 (new dep), node --test runner, `@testcontainers/localstack` for integration.

**Reference:**
- `arcnode/ems/boot_strategy_adr.md` — ADR-003 normative behavior matrix + failure modes
- `arcnode/ems/docs/superpowers/specs/2026-05-10-day-1-boot-design.md` — implementation contract
- `arcnode/edp-api/src/bom_generator/manifest_client.py` — Python S3 client with endpoint override (the pattern this mirrors)

### Step 3: Implement `src/seed/seed_from_s3.ts`

```typescript
/**
 * Boot-time DTM fetch + seed per ADR-003.
 *
 * URL set + table empty → fetch + parse + validate + seed
 * URL set + table populated → fetch + skip seed (don't overwrite operator changes)
 * URL unset / null → graceful empty start
 * Any fetch/parse/validate/catalog error when URL set → fatal (caller propagates)
 */

import { Logger } from "@nestjs/common";
import type { INestApplicationContext } from "@nestjs/common";
import { S3Client, GetObjectCommand } from "@aws-sdk/client-s3";
import type { Readable } from "node:stream";
import { Dtm } from "../topology/dtm.schema";
import type { DtmType } from "../topology/dtm.schema";
import { TopologyService } from "../topology/topology.service";

interface S3Url {
  bucket: string;
  key: string;
}

function parseS3Url(url: string): S3Url {
  const match = /^s3:\/\/([^/]+)\/(.+)$/.exec(url);
  if (!match) {
    throw new Error(`s3:// url required, got ${url}`);
  }
  return { bucket: match[1], key: match[2] };
}

async function streamToString(stream: Readable): Promise<string> {
  const chunks: Buffer[] = [];
  for await (const chunk of stream) {
    chunks.push(Buffer.isBuffer(chunk) ? chunk : Buffer.from(chunk));
  }
  return Buffer.concat(chunks).toString("utf8");
}

/**
 * Fetch DTM from S3 (or S3-compatible endpoint) and seed topology if empty.
 *
 * @param app Assembled NestJS application context (for service.get())
 * @param url s3://bucket/key, or null to skip fetch
 * @param endpointUrl Override for S3 endpoint (LocalStack/minio); null = real AWS S3
 * @param logger Winston-compatible logger
 * @param s3 Optional pre-constructed client (tests inject mocks)
 */
export async function seedFromS3(
  app: INestApplicationContext,
  url: string | null,
  endpointUrl: string | null,
  logger: Logger,
  s3?: S3Client,
): Promise<void> {
  if (url === null) {
    logger.log("no boot_dtm_s3_url configured; starting empty");
    return;
  }

  const { bucket, key } = parseS3Url(url);
  const client =
    s3 ??
    new S3Client({
      ...(endpointUrl ? { endpoint: endpointUrl, forcePathStyle: true } : {}),
    });

  const response = await client.send(
    new GetObjectCommand({ Bucket: bucket, Key: key }),
  );
  if (response.Body === undefined) {
    throw new Error(`s3 object ${url} has no body`);
  }
  const body = await streamToString(response.Body as Readable);
  const raw = JSON.parse(body) as unknown;
  const dtm: DtmType = Dtm.parse(raw);

  const service = app.get(TopologyService);
  service.validateAgainstCatalog(dtm);

  const existing = await service.getLatest();
  if (existing !== null) {
    logger.log(`topology already populated; skipping seed from ${url}`);
    return;
  }
  await service.save(dtm);
  logger.log(`seeded topology from ${url}`);
}
```

async function bootstrap(): Promise<void> {
  const cfg = loadConfig();

  logger.info(`Running with Config ${JSON.stringify(cfg)}`);
  const app = await NestFactory.create(AppModuleWithDatabase);
